## 🛠 Технічні вимоги та стек технологій

### 1. Дозволений стек
* **HTML5:** Семантична, якісна размітка.
* **CSS3:** Ванільний CSS (Flexbox, CSS Grid, змінні CSS, адаптивний дизайн).
* **Vanilla JavaScript (ES6+):** Чистий JS без фреймворків чи сторонніх бібліотек.

### 2. Ключові обмеження (Строгі правила)
* 🚫 **Без фреймворків:** Категорично заборонено використовувати React, Vue, Angular, Svelte, Next.js тощо.
* 🚫 **Без CSS-фреймворків:** Не використовувати TailwindCSS, Bootstrap чи аналоги.
* 🚫 **Без інструментів збірки:** Сайт є статичним. Жодних Webpack, Vite, Babel чи складних завдань збірки Node.js.

## 🎯 Правила роботи ШІ з кодом

1. **Сумісність:** Писати чистий код, який відкривається в будь-якому браузері без попереднього компілювання.
2. **Семантика:** Використовувати семантичні теги HTML5 (`<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`).
3. **Адаптивність:** Створювати адаптивний дизайн під мобільні та десктопні пристрої.
4. **Збереження вимог:** При внесенні змін не порушувати вимогу щодо чистого JS/HTML/CSS.
